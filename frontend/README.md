# Jamium Frontend

A Next.js + Tailwind + shadcn UI for music learning and composition with chord analysis, visualizations, and AI tools.

## Getting started

```bash
cd frontend
npm install
npm run dev
```

The app boots at http://localhost:3000.

## Features

- Interactive songwriting assistant with AI-powered composition
- Real-time chord analysis and visualization
- Jam assistant with metronome and chord progressions
- Music theory tools and practice utilities
